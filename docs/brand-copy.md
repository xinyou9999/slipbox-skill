## English

### Positioning

slipbox | AI-powered card notes across agents

### Tagline

Organize card notes with AI. Build your collection over time. Reuse it across agents.

### Description

slipbox is an AI-powered card note tool that works across agents. Use AI to capture, organize, and retrieve your notes, and keep reusing the same collection across platforms.

## Usage and meaning

- Keep the brand lowercase: `slipbox`.
- Keep the hierarchy: positioning, tagline, description. Smaller surfaces may use just the appropriate line; line wrapping may change, wording should not.
- “Card notes” preserves the product's focus on individual note cards. Do not replace it with generic “knowledge” or “AI memory.”
- “Agents” refers to the host applications. AI assistance comes from the current host's model; the Skill does not include its own model service.
- “Across agents” means users can reuse their collection with different compatible hosts, including when switching hosts. It does not require simultaneous multi-agent work.
- Reuse currently requires access to the same local library, or manual transfer of the Markdown cards and tag library followed by index rebuilding. It does not claim automatic cloud sync, built-in import/export commands, or universal host compatibility.
- Host installation evidence remains in [INSTALL.md](INSTALL.md). This copy does not change that evidence.
