# Roadmap

The core loop is capture → governed tags → retrieve → review. Priority follows real installation and usage problems.

## First public candidate

Portable Skill bundles, documented routes for Codex/Hermes/OpenClaw/WorkBuddy, an experimental DeepSeek harness route, synthetic-note demo, build checks and transparent host verification levels.

## Next evidence we need

- Reproducible installation reports from the targeted hosts.
- Examples of a card being useful again in a real workflow.
- Reports of confusing tag decisions or retrieval limitations.

## Evaluate after feedback

Better retrieval and citations; lightweight card relationships; an optional read-only MCP adapter reusing the same core. A graphical interface is a separate future feature, not part of today's Skill.

No dates are promised for cloud synchronization, accounts, attachments, semantic indexing or mobile/desktop apps. We do not prioritize a larger feature checklist over successful first use.
